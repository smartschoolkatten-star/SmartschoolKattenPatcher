# Smartschool Katten

Smartschool met kattenprofielfoto’s, een dagelijkse streak en eigen kattenfoto’s.
Beschikbaar als browserextensie en als Android-app.

- [Downloadpagina](https://smartschoolkatten-star.github.io/SmartschoolKattenPatcher/)
- [Chrome](https://chromewebstore.google.com/detail/smartschool-katten/ndembkilcdoipaefhmbnoiamccnkjgco)
- [Firefox](https://addons.mozilla.org/en-US/firefox/addon/smartschool-katten/)
- [Android-APK](https://github.com/smartschoolkatten-star/SmartschoolKattenPatcher/releases/latest/download/Smartschool-Katten.apk)

Installeer voor Android de APK. De app controleert zelf op nieuwe versies;
Android vraagt je om de installatie van een update te bevestigen. Android 12L
of nieuwer en een 64-bits ARM-toestel zijn vereist.

In Android Studio kun je het project synchroniseren, **Smartschool Katten**
selecteren en met de Play-knop rechtstreeks starten. Zie [bouwen en ontwikkelen](docs/APK-APP.md).
De handtekening blijft behouden bij updates. Privésleutels staan buiten deze repository.

De vorige patcher is vervangen door een rechtstreekse APK. De oudere
[patcher-notities](docs/LEGACY-PATCHER.md) blijven als archief beschikbaar.
